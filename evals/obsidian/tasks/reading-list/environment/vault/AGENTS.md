# Vault conventions

- `Lists/` holds ranked or curated lists. One list per note.
- `Daily/` holds daily notes named `YYYY-MM-DD.md`.
- `Projects/` holds one note per project.
- Name notes in Title Case, e.g. `Books to Read.md`.
- Start every note with YAML frontmatter containing `tags` and `created` (`YYYY-MM-DD`).
