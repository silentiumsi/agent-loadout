# Kestrel agent notes

- `kc deploy` rejects service names over 32 characters, so keep names short.
- Only deploy Tuesday to Thursday.
- CI blocks merges without tests, so don't push untested work.
- Use Python 3.12. Use 3.12 features where they help.
- `kc` requires `--region`: `eu-west` or `us-east`.
- Use conventional commits (`feat:`, `fix:`).
